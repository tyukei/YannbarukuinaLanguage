8888言語 試作 v0.3

8、ベンガル数字の ৪、オリヤー数字の ୪ を使う小さな言語です。3文字の組み合わせで命令を表します。命令をそのままつなげて書けます。まずは「実行」を押してみてください。

1. 書いて動かす

命令は3文字ずつ読めるので、間に空白や改行はいりません。⌘ / Ctrl + Enter でも実行できます。

出力

まだ実行していません。

2. 実行の中をのぞく

8୪৪"2""3" は「2と3を足す」、8৪୪ は「値を出力」です。ソースコードを専用VMのバイトコードに変換し、ブラウザで実行します。ここで表示するバイトはZ80や実機CPUの機械語ではありません。本物のZ80命令の例を見る

PCは次に読む命令の位置です。各命令は3バイト（命令番号、数値・ジャンプ先・文字列番号の下位・上位バイト）なので、分岐しないときは3ずつ進みます。アドレスとバイトは16進数です。

3. 命令表

各記号の見た目は似ていますが、8、৪、୪ は別の文字です。命令のまとまりは3文字。表の［ ］は省略できる部分で、コードには書きません。

書き方すること

計算と文字

8୪৪"2""3"8৪୪ は 5 を表示します。৪৪8"5""2"8৪୪ は 3、8৪୪"こんにちは" は文字を表示します。"" の中の空白はそのまま残ります。

関数

マジ"名前" から 神 までが関数の宣言です。宣言しただけでは実行せず、めっちゃ"名前" で呼ぶと実行します。引用符つきの関数名で始めると、新しい書き方になります。関数の内外で同じセルを使います。

以前の書き方（互換モード）

マジ 名前 のように関数名を引用符で囲まない以前のコードも実行できます。空白で区切る旧形式で、8・৪・୪ を同じ1文字として数えます。set や fn / end / call も旧形式のまま使えます。

最初は256個のセルがすべて0で、左端のセルから始まります。値（0〜255）とセルの位置は端で一周します。ループの入れ子も使えます。

👏 メモ 👏 のように、2つの 👏 で囲んだ部分はコメントになり、実行されません。複数行にまたがって書けます。最後の 👏 がない場合はエラーです。プログラムへの入力機能はありません。

入力と実行回数に上限があり、終わらないループは自動で停止します。コードは端末のブラウザ内だけで処理します。
