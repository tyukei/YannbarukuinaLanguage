8888言語 試作 v0.5

8、ベンガル数字の ৪、オリヤー数字の ୪ を使う小さな言語です。3文字の組み合わせで命令を表します。命令をそのままつなげて書けます。まずは「実行」を押してみてください。

命令は3文字ずつ読めるので、間に空白や改行はいりません。⌘ / Ctrl + Enter でも実行できます。

    3. 命令表
    

    命令は3文字。先頭の 8 は計算、৪ は値、୪ は移動・ループ。値は 神 で区切ります。
    

    命令意味書き方の例
    

    すべての命令（先頭の文字で分類）

    8：計算
    命令意味
    

    ৪：値
    命令意味
    

    ୪：移動・ループ
    命令意味
    

    

    計算と文字
    

    88৪神2神3神৪৪৪ は 5 を表示します。88୪神5神2神৪৪৪ は 3、৪৪৪神こんにちは神 は文字を表示します。神 は値の境界です。たとえば 88৪神8神3神 の先頭の 88৪ は足し算の命令、神8神 の 8 は計算する数です。表示する文字の中では空白も残り、\神 と書けば文字として「神」を表示できます。
    

    関数
    

    マジ名前{…} で関数を宣言します。中身だけを { } で囲み、めっちゃ{名前} で実行します。関数の内外で同じセルを使います。
    

    以前の書き方（互換モード）
    マジ 名前 のように関数名を引用符で囲まない以前のコードも実行できます。マジ"名前" から始まる前の試作（v0.3）や、旧命令の並びもそのまま動きます。空白で区切る旧形式で、8・৪・୪ を同じ1文字として数えます。set や fn / end / call も旧形式のまま使えます。
    

    最初は256個のセルがすべて0で、左端のセルから始まります。値（0〜255）とセルの位置は端で一周します。ループの入れ子も使えます。
    

    👏 メモ 👏 のように、2つの 👏 で囲んだ部分はコメントになり、実行されません。複数行にまたがって書けます。最後の 👏 がない場合はエラーです。プログラムへの入力機能はありません。
    

    入力と実行回数に上限があり、終わらないループは自動で停止します。コードは端末のブラウザ内だけで処理します。
