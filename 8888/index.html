8、ベンガル数字の ৪、オリヤー数字の ୪ を使う小さな言語です。この試作ではどれも1文字と数え、混ぜて書けます。まずは「実行」を押してみてください。

3. 命令表

数字だけで書く命令に加えて、試作 v0.2 ではキーワードも使えます。

書き方すること

計算と文字

set 2 push set 3 add 88888 は、左の値 2 を保存してから 3 を足し、5 を表示します。sub は「保存した値 − 現在値」です。set 65 char は ASCII の A を出力します。

関数

マジ 名前 から end までが関数の宣言です。宣言しただけでは実行せず、めっちゃ 名前 で呼ぶと実行します。fn と call も同じ意味で使えます。関数の内外で同じセルを使います。引数や戻り値はまだありません。

最初は256個のセルがすべて0で、左端のセルから始まります。値（0〜255）とセルの位置は端で一周します。ループの入れ子も使えます。

👏 メモ 👏 のように、2つの 👏 で囲んだ部分はコメントになり、実行されません。複数行にまたがって書けます。最後の 👏 がない場合はエラーです。プログラムへの入力機能はありません。

入力と実行回数に上限があり、終わらないループは自動で停止します。コードは端末のブラウザ内だけで処理します。
